# Still Up

A patch-notes-style changelog for my projects. It shows what I'm working on, what's changed, and what's still being maintained.

## What's in it

- **Project status cards**: Active, Maintenance, Inactive
- **Patch entries**: Shown in feed, each has tags ('NEW', 'UPDATE', 'FIX', 'KNOWN ISSUES')

## Tech Stack

- Vite
- React
- TypeScript
- Vercel

## Getting Started

```
npm install
npm run dev
```
